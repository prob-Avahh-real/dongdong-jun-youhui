# 动动菌友荟 (DongDongJunYouHui)

Mobile myco-life simulation game. Explore a fungal world, collect mushrooms, befriend NPCs, and build your mycological collection.

## Tech Stack
- **Language:** JavaScript (Vanilla)
- **Rendering:** HTML5 Canvas
- **Audio:** Web Audio API (procedural)
- **Storage:** localStorage
- **PWA:** Manifest + Service Worker ready

## Getting Started
Open `index.html` in a mobile browser — no build step required.

## Features
- Open world exploration with virtual joystick
- Resource gathering: mushrooms, trees, rocks, logs, fairy rings
- 15+ collectible items with rarity tiers
- 4 NPCs with gift/friendship system
- Shop economy (sell items for mushroom coins)
- Day/night cycle with visual effects
- Procedural audio sound effects
- Save/Load with localStorage
- PWA support
